# User stories

## Start a recording session
As a technician, I want to start a recording for a participant so that NeuroPulse can collect telemetry. The participant must be active; the assigned device must be connected, have at least 10% battery, and have no active recording.

## Assign a device
As an operator, I want to assign an available device so that a participant can record. An assigned device should not be silently moved. What should happen to historical assignments is intentionally unspecified.

## Review telemetry
As a technician, I want to inspect readings and signal quality for a session. The acceptable boundary behaviour for gaps and unusual timestamps is intentionally ambiguous.

## Reset a class exercise
As an instructor, I want to restore known records and normal simulator behaviour so every cohort can begin from equivalent data.
