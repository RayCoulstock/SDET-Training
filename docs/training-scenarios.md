# Training scenarios

## Phase 1 — Playwright
Map journeys, write semantic locators, compare resilient and generated selectors, review waits, and capture a trace for a recording workflow.
## Phase 1 — API Testing
Explore filters and boundary inputs in Swagger/Postman. Compare UI constraints with direct requests and create a negative-test charter.
## Phase 1 — AI-Assisted Testing
Give an AI the user stories or OpenAPI schema, critique its boundaries, and ask it to explain a failure without accepting the first answer.
## Phase 2 — Playwright Architecture
Grow the starter suite, identify duplicated setup, compare API setup with UI setup, and discuss when Page Objects or fixtures earn their cost.
## Phase 2 — Pact
Treat NeuroPulse.Api as consumer and the simulator as provider. Define the smallest useful V1 interaction, then investigate the V2 scenario.
## Phase 2 — JMeter
Establish a telemetry baseline, enable Performance Stress, increase safe concurrency, and interpret percentiles, throughput, and errors.
## Phase 2 — Designing for Testability
Review `SessionService`: identify concrete time, randomness, HTTP, and persistence dependencies and propose incremental seams.
## Phase 2 — Exploratory Testing
Use Slow, Unreliable, and Exploratory presets. Create charters around state freshness, retries, concurrency, and duration boundaries.
## Phase 2 — Developer Coaching
Review the fixed wait, clickable div, error presentation, and business-rule gaps. Practise describing impact and suggesting a proportionate change.
