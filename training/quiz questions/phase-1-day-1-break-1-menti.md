# Phase 1 — Day 1 — Tea break 1 Menti

1. **What best describes shift-left testing?**
   - A. Moving every test into unit testing
   - **B. Creating useful feedback earlier in the delivery lifecycle**
   - C. Running UI tests before API tests
   - D. Giving all testing work to developers
   - Feedback: Shift-left is earlier feedback and prevention, not relocating every check.

2. **Who owns quality on an effective engineering team?**
   - A. The SDET alone
   - B. The product owner alone
   - **C. The whole team, with explicit responsibilities**
   - D. Whoever finds the most defects
   - Feedback: Quality is shared, while specialist expertise and responsibilities still matter.

3. **Which is the lowest useful level for checking that a battery level of 9% is rejected by the Start Recording rule?**
   - A. End-to-end UI only
   - **B. Service/unit or API**
   - C. Performance test
   - D. Visual regression test
   - Feedback: The business rule can be checked quickly and diagnostically below the UI.

4. **What should primarily determine where a test belongs?**
   - A. A fixed pyramid quota
   - B. The tester's favourite tool
   - **C. Risk, fidelity, feedback speed, and maintenance cost**
   - D. The longest possible user journey
   - Feedback: Test levels are a portfolio decision driven by the risk and architecture.

5. **Which activity is most characteristic of an SDET?**
   - A. Automating every manual test through the UI
   - B. Waiting until implementation is complete
   - **C. Helping clarify a rule before code is written**
   - D. Acting as the team's release gatekeeper
   - Feedback: Prevention and testability are central to the role.
