# Activity 7 — Phase 1 Assessment Preparation

**Day:** 2  
**Activity:** 7  
**Related slides:** Phase 1 Assessment — The Shape  
**Suggested time:** 10 minutes

## Objective

Plan the evidence needed to demonstrate Phase 1 capability without starting or guessing the assessment scenario.

## Your Task

Choose one bounded NeuroPulse risk involving a participant, device, session, or telemetry. It is an example for planning only, not an assessment answer.

Create an evidence map with these rows:

| Capability | Decision you may need to defend | Useful evidence | What would not be enough |
|---|---|---|---|
| Test strategy and placement | | | |
| Focused Playwright coverage | | | |
| API investigation and negative testing | | | |
| Risk communication | | | |
| Transparent, appropriate AI use | | | |

Add a sensible order for collecting the evidence. Identify one dependency or setup assumption, one way to preserve diagnostic evidence, and one point where human review is essential.

Pair with another learner and challenge one another's maps: does each item demonstrate a capability, or merely show activity and test count?

## Things to Investigate

- Which evidence proves a reasoned choice rather than tool usage?
- How can UI and API evidence complement rather than duplicate each other?
- What makes a risk statement clear and bounded?
- How would you disclose AI assistance and verify its contribution?

## Evidence

Keep the completed map and be ready to explain one strong evidence choice and one gap you still need to address.

## Stretch Challenge

Remove one proposed artefact while preserving the strength of the evidence. Explain why less evidence can sometimes be clearer.

## Hints

1. Start with the quality risk, then select the tool and test level.
2. Passing output is useful, but intent, scope, and diagnostic artefacts may also matter.
3. “AI generated this” does not establish correctness or responsible use.

## Discussion

- Which evidence best demonstrates SDET judgement?
- Where were you collecting volume rather than confidence?
- What will you do first when the assessment scenario is provided?
