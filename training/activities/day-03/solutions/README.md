## Facilitation guidance

- Keep Normal simulator state before and after scenario-based demonstrations.
- Never run global reset concurrently with stateful tests or another learner's work.
- Performance numbers must come from the learner's run; the solution intentionally
  supplies an interpretation framework rather than fabricated results.
- AI-produced analysis and course content still require human verification and review.
