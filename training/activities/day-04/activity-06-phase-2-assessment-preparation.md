# Activity 6 — Phase 2 Assessment Preparation

**Day:** 4  
**Activity:** 6  
**Related slides:** Phase 2 Assessment — The Shape; Programme Transition  
**Suggested time:** 10 minutes

## Objective

Plan evidence that demonstrates integrated SDET judgement without guessing or beginning the eventual assessment scenario.

## Your Task

Choose a bounded **example** NeuroPulse risk crossing at least two of UI, API, simulator, persistence, or telemetry. This is evidence-planning practice, not an assessment answer.

Complete the map:

| Capability | Decision to defend | Proportionate evidence | Limitation/trade-off | Quality question for the team |
|---|---|---|---|---|
| Risk analysis and test-level choice | | | | |
| Maintainable automation | | | | |
| API or contract investigation | | | | |
| Performance reasoning | | | | |
| Testability improvement | | | | |
| Exploratory evidence and risk communication | | | | |

Draw an order for gathering evidence that gives early, diagnostic feedback before expensive system-wide checks. Mark:

- one assumption you would verify before testing;
- one decision point where evidence changes the approach;
- one real dependency you would retain;
- one honest limitation you would communicate; and
- one example of collaboration or coaching, not only an artefact you produced.

Pair-review the map. Challenge whether each item shows reasoning and impact or merely proves a tool was used. Do not invent detailed assessment requirements beyond the capability areas in the slides.

## Evidence

Keep the completed map, collection order, five marked items, and one revision made after peer challenge.

## Stretch Challenge

Prepare a 60-second showcase explanation: risk, decision, strongest evidence, limitation, and next team action. Remove any metric or artefact that would not change a decision.

## Hints

1. Begin with the risk and decision, not Playwright, Pact, Postman, or JMeter.
2. Passing tests alone do not explain scope, testability, uncertainty, or trade-offs.
3. The strongest portfolio combines controlled evidence with selected realistic boundaries.

## Discussion

- Which evidence best demonstrates embedded quality advocacy?
- Where did your plan duplicate evidence across test levels?
- What will you need to defend rather than merely show?
